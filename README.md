# Jason Penrod — portfolio

Static personal site. No build step: plain HTML, Google Fonts, one self-contained
stylesheet per page. Deployed on Vercel (Framework preset: Other, root directory: `.`).

- `index.html` — home
- `work/` — case studies (youth-as-experts, data-and-design, step-up-your-game, tarot-copilot)
- `images/` — case-study screens (added as they are exported)
